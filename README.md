# Українська локалізація Katawa Shoujo

Репозиторій містить українські файли локалізації Katawa Shoujo для Ren’Py та англомовні оригінали для звіряння.

## Структура

- `game/tl/ukrainian/` — українські `.rpy` файли.
- `game/tl/english/` — англійські файли-джерела для порівняння.
- `docs/STYLEGUIDE.md` — правила перекладу, транслітерації та стилю.
- `docs/GLOSSARY.md` — узгоджені імена й терміни.
- `docs/PROGRESS.md` — наявність файлів і стан вичитки.

## Як долучитися

Читайте [CONTRIBUTING.md](CONTRIBUTING.md) і [посібник зі стилю](docs/STYLEGUIDE.md). Повідомити про помилку або запропонувати варіант перекладу можна через шаблони Issues на GitHub.

Файли локалізації призначені лише для modern версії гри (Ren'Py 8 Branch). Зміни сценарних рядків мають зберігати структуру Ren’Py, ідентифікатори та керівні теги оригіналу.
