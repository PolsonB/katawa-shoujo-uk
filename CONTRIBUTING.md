# Як долучитися


1. Перевірте наявні Issues, щоб не дублювати роботу.
2. Для виправлення створіть гілку й змініть відповідний файл у `game/tl/ukrainian/`.
3. Звірте змінені рядки з відповідним файлом у `game/tl/english/`.
4. Дотримуйтеся [STYLEGUIDE.md](docs/STYLEGUIDE.md) та термінів із [GLOSSARY.md](docs/GLOSSARY.md).
5. Не змінюйте ідентифікатори рядків, Ren’Py-теги форматування, змінні й керівні конструкції, якщо це не є частиною виправлення.
6. У PR наведіть файл і рядок/сцену, поясніть причину зміни та вкажіть, чи перевірено відображення в грі.

Для одиничної одруківки або питання створіть Issue за відповідним шаблоном. Не додавайте до коміту файли гри, збереження чи згенеровані артефакти, якщо вони не потрібні для зміни.


## Встановлення перекладу

Українські `.rpy` файли можна просто скопіювати з `game/tl/ukrainian/` у відповідну папку `game/` в каталозі встановленої modern-версії гри (Ren’Py 8 Branch). Перепаковувати архіви, створювати патч чи виконувати додаткову збірку не потрібно. Достатньо лише перекинути .rpy файли в гру.
