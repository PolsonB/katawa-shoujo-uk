# ✍️ Посібник зі стилю перекладу Katawa Shoujo

Цей гайдлайн визначає стандарти художнього стилю, мовних правил та взаємодії з рушієм Ren'Py.
---

## 1. Суфікси та звертання

### Прізвиська Міші
Міша використовує скорочені пестливі прізвиська. Вони пишуться **разом, з великої літери та з двома «ч»**:
*   `Hicchan` ➔ **Хіччан** (відмінюється: *Хіччана, Хіччану, Хіччаном; кличний: «Хіччане!» або коротке «Хіччан!»*).
*   `Shicchan` ➔ **Шіччан** (не відмінюється: *«Шіччан пішла»*, *«запитати в Шіччан»*).
*   `Yuu-chan` ➔ **Ю-чан** (звертання до бібліотекарки).
*   Сміх Міші: **«Ва-ха-ха~!»**, **«Ва-ха-ха-ха~!»** (через дефіси, з тильдою).

### Японські суфікси ввічливості
Пишуться через дефіс, з малої літери:
*   `-kun` ➔ **-кун** (*Хісао-кун*)
*   `-chan` ➔ **-чян** (*Ханако-чян*, через «я»)
*   `-san` ➔ **-сан** (*Шідзуне-сан*)
*   `-sensei` ➔ **-сенсей** (*Муто-сенсей*)
*   `-senpai` ➔ **-семпай** (*Юко-семпай*)

## 2. Характер та манера мовлення персонажів (Voice & Tone)

*   **Хісао (Оповідач):** Стриманий, схильний до рефлексії, іноді трохи саркастичний чи меланхолійний. Речення будуються виважено, без надмірного сленгу. Всі думки від 1-ї особи — строго в **чоловічому роді** (*побачив, подумав*).
*   **Рін:** Нестандартне мислення, потік свідомості. Може говорити абсурдно, фрагментарно, обривати думки на пів слові.
*   **Ліллі:** Стримана, чемна аристократка. Мова багата, елегантна, без жодного натяку на фамільярність чи сучасний сленг.
*   **Шідзуне:** Прагматична, владна, ділова. Її слова завжди передаються через Мішу — формулювання чіткі, короткі, без зайвих сентиментів.
*   **Кенджі:** Параноїк, зациклений на теоріях змови та «феміністичній загрозі». Мова швидка, плутана, сповнена псевдонаукових термінів, з різкими перепадами емоцій.
