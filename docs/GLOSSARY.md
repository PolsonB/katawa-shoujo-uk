## 4. Специфічні терміни

*   `Student Council` ➔ **Учнівська рада** (НЕ «студентська рада»).
*   `Student Council President` ➔ **голова Учнівської ради** (НЕ президент).
*   `Students` ➔ **учні / школярі / старшокласники** (НЕ студенти, це старша школа).
*   `Student ID` ➔ **учнівський квиток**.
*   `Clubs` (мистецькі, наукові) ➔ **гуртки** (*художній гурток*, *науковий гурток*, *чайний гурток*).
*   `Clubs` (спортивні) ➔ **секції** (*легкоатлетична секція*, *секція бігу*).
*   `Stalls` ➔ **ятки**.
*   `Sign language` ➔ **жестова мова** (не вживати форму «мова жестів», бо мають різні значення).
*   `Arrhythmia` ➔ **аритмія** (діагноз Хісао).
